# ApexFlight

开源无人机调参软件（Betaflight 调参工具），全本地运行、零 API、保护飞手隐私。

- 开源协议：GPL-3.0（见 `LICENSE`）
- 当前版本：v0.7

## 功能（v0.7）

**📊 仪表盘**
- 飞控信息：固件版本、完整板型（如 DAKEFPVH743）、MCU、电机通道数
- 电源/链路：电池电压、电流、耗电量、信号强度 RSSI
- 飞控状态：CPU 负载、循环时间、解锁禁用原因（与 Betaflight 4.5 标志位一一对应）
- 人工地平线：拿起飞机转动，姿态实时跟随（横滚/俯仰/航向）

**🎛️ PID 调参**
- 读取完整 PID 表（兼容新旧固件：5 组 / 10 组自动识别）
- 表格直接编辑，一键写入飞控并保存到闪存
- 写入前自动备份当前参数到 `backups/`（JSON 格式，带时间戳）
- 随时从备份文件恢复

**🎯 Rates 调参（v0.5 新增）**
- 三轴（横滚/俯仰/偏航）RC Rate / Super Rate / Expo 滑块实时调整
- **手感曲线可视化**：摇杆偏转→角速度曲线实时预览，拖动滑块立即可见
- 满杆角速度读数；非经典 Rates 类型自动提示
- 数据协议与 Betaflight 4.5 固件逐字节对齐（read-modify-write，未知字段原样保留）

**🌊 滤波器设置（v0.5 新增）**
- 静态低通（陀螺仪×2 / D 项×2 / 偏航）、动态低通、动态陷波、RPM 滤波全字段调节
- **与黑匣子频谱联动**：FFT 找到的噪声峰自动同步显示到本页，指导截止频率设置
- 关闭滤波（截止频率=0）时写入前给出红色安全警告

**💾 调参方案（v0.5 新增）**
- 预设 = 一整套调参状态（PID + Rates + 滤波器），保存到 `presets/`
- 一键保存当前飞控状态为预设（如"花飞手感"/"竞速稳拍"）
- 一键应用预设完整写回飞控；应用前自动全量备份，随时可调回来

**⚙️ 电机测试**
- 按实际电机通道数生成滑块，逐个测试电机
- 双重安全确认（必须勾选"已拆桨"才能解锁滑块）
- 一键全部停止；断开/关闭窗口时自动停转

**📡 接收机监视**
- 实时显示全部 RC 通道数值（1000~2000 范围可视化）

**📈 黑匣子分析（对标 BF Blackbox Explorer）**
- 打开 .bbl / .bfl 二进制日志（内置官方解码器），**多段飞行记录自动识别、下拉切换**
- **日志信息面板**：固件版本、机名、板子、PID 循环周期、PID 值、滤波配置等头部元数据
- **多轨道堆叠视图**：每个通道一条独立轨道，共享时间轴（BF 黑匣子浏览器同款布局）
- **鼠标游标读数**：移动鼠标显示该时刻各通道精确数值
- **时间范围裁剪**：只看指定区间
- **频谱分析（FFT）**：自动标注噪声峰频率，指导滤波器设置
- 通道开关选择（BF 同款 toggle 样式）、中文名、归一化对比、统计信息
- **📥 从飞控下载**：MSPv2 大帧读取板载闪存（约 47KB/s），支持只下载"最近 N MB"
  并自动向前定位最近一次飞行的日志起点，下载后可自动清空闪存
- **🔀 双日志对比模式（v0.7 新增）**：加载第二段日志叠加显示（橙色曲线），
  调参前后效果一目了然，统计区显示"当前均值 vs 对比均值"
- **✈️ 日志类型智能判别（v0.7 新增）**：打开日志自动判断是"正常飞行数据"还是
  "疑似地面空转（通电未装桨）"——依据平均电流、陀螺仪 RMS 噪声、姿态设定活动度
  等特征打分，给出置信度和判别理由，空转日志会在状态栏提醒
- 崩溃自动记录 `logs/crash.log`（界面异常弹窗提示，不再无声消失）

**🤖 AI 助手（v0.6 深度联动）**
- 接入 Ollama 本地大模型，飞行数据不出电脑、零云端（推荐 qwen2.5:3b 深度分析）
- **🧠 综合调参建议**：一键把飞控全部真实数据（PID + Rates + 滤波器 + 黑匣子
  结构化分析）发给 AI，生成按优先级排列、带风险提示的调参方案
- **🤖 黑匣子 AI 解读**：黑匣子页一键把当前日志的结构化分析发给 AI 解读；
  AI 会先判断日志类型是否可信（飞行→给调参方向，空转→说明能验证什么）；
  对比模式下可对两段日志做差异分析
- **结构化分析引擎**：自动计算各轴陀螺仪 RMS 噪声与 FFT 主峰、设定值→陀螺仪
  跟踪滞后（互相关）、电机饱和时间占比、最低电压等调参关键指标
- 流式对话（逐字输出）、可随时停止、多轮上下文、一键清空

## 运行方式

双击 `启动ApexFlight.bat` 即可；或在项目根目录：

```bash
pip install -r requirements.txt
python src/main.py
```

运行前：插入飞控 USB，关闭 Betaflight Configurator（串口独占）。

## 目录结构

```
ApexFlight/
├── assets/             # 图标资源（icon.png）
├── backups/            # 调参自动备份（JSON，写入类操作前自动生成）
├── presets/            # 调参方案预设（PID + Rates + 滤波器整套快照）
├── logs/               # 黑匣子日志（.bbl）与崩溃日志（crash.log）
├── tools/              # 本地工具（Ollama 安装包等）
├── src/
│   ├── main.py           # 主窗口 + 后台串口线程 + 程序入口
│   ├── apex_msp.py       # MSP 协议编解码（v1/v2 帧、CRC8）
│   ├── apex_fc.py        # 飞控查询/写入、备份、调参快照
│   ├── apex_blackbox.py  # 黑匣子解码、统计、日志类型判别
│   ├── apex_ai.py        # Ollama AI 助手通信
│   └── apex_widgets.py   # 自定义控件（开关、姿态仪）
├── tests/
│   ├── test_core.py      # 核心逻辑单元测试（python tests/test_core.py）
│   └── smoke_v07.py      # 离屏界面冒烟测试
├── 启动ApexFlight.bat   # 一键启动脚本
├── requirements.txt    # 依赖：PyQt6、pyserial
├── README.md
├── LICENSE             # GPL-3.0
└── .gitignore
```

## AI 助手说明

AI 助手依赖本机的 [Ollama](https://ollama.com) 服务（已在 `tools/` 留有安装包）。
首次使用：安装 Ollama 后执行 `ollama pull qwen2.5:1.5b`（深度分析模型
`qwen2.5:3b` 可选），然后在 AI 助手页点「🔄 刷新状态」。
有 NVIDIA 显卡时推理会走 GPU；显卡驱动异常时自动退回 CPU（速度较慢）。

## 黑匣子解码器

二进制日志（.bbl/.bfl）解码依赖官方开源解码器
[blackbox-tools](https://github.com/cleanflight/blackbox-tools) 的
`blackbox_decode.exe`（GPL-3.0），体积原因未收入本仓库。
请自行编译或下载后放到 `tools/blackbox_decode.exe`；
没有解码器时仍可打开已解码的 CSV 和演示日志。
