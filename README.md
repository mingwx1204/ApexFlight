# ApexFlight

开源无人机调参软件（Betaflight 调参工具），全本地运行、零 API、保护飞手隐私。

- 开源协议：GPL-3.0（见 `LICENSE`）
- 当前版本：v1.00

## 功能（v1.00）

**📊 仪表盘**
- 飞控信息：固件版本、完整板型（如 DAKEFPVH743）、MCU、电机通道数
- 电源/链路：电池电压、电流、耗电量、信号强度 RSSI
- 飞控状态：CPU 负载、循环时间、解锁禁用原因（与 Betaflight 4.5 标志位一一对应）
- 人工地平线：拿起飞机转动，姿态实时跟随（横滚/俯仰/航向）

**🎛️ PID 调参**
- 读取完整 PID 表（兼容新旧固件：5 组 / 10 组自动识别）
- 表格直接编辑，一键写入飞控并保存到闪存
- 写入前自动备份当前参数到 `backups/`（JSON 格式，带时间戳）
- 随时从备份文件恢复

**🎯 Rates 调参（v0.5 新增）**
- 三轴（横滚/俯仰/偏航）RC Rate / Super Rate / Expo 滑块实时调整
- **手感曲线可视化**：摇杆偏转→角速度曲线实时预览，拖动滑块立即可见
- 满杆角速度读数；非经典 Rates 类型自动提示
- 数据协议与 Betaflight 4.5 固件逐字节对齐（read-modify-write，未知字段原样保留）

**🌊 滤波器设置（v0.5 新增）**
- 静态低通（陀螺仪×2 / D 项×2 / 偏航）、动态低通、动态陷波、RPM 滤波全字段调节
- **与黑匣子频谱联动**：FFT 找到的噪声峰自动同步显示到本页，指导截止频率设置
- 关闭滤波（截止频率=0）时写入前给出红色安全警告

**💾 调参方案（v0.5 新增）**
- 预设 = 一整套调参状态（PID + Rates + 滤波器），保存到 `presets/`
- 一键保存当前飞控状态为预设（如"花飞手感"/"竞速稳拍"）
- 一键应用预设完整写回飞控；应用前自动全量备份，随时可调回来

**⚙️ 电机测试（v0.99 对齐 BF 官方最新 MotorsTab）**
- **电机位置示意图**：BF QUAD X 编号（4 左前 / 2 右前 / 3 左后 / 1 右后），
  红色机头箭头，转动中的电机随油门高亮；非四轴自动切换圆环排布
- **DShot 语义直读**：滑块即 1000~2000µs 输出值，10ms 发送缓冲，
  5Hz 读回 MSP_MOTOR 遥测（RPM / 错误 / 温度占位行）
- **主控总滑块**：一个橙色滑块同时驱动全部电机（BF 同款），整体试转/排查用
- 红色危险警示框单开关确认（必须勾选"已拆桨"才能解锁滑块）
- 一键停转电机；断开/关闭窗口/停用开关时自动停转，停转值固定 1000

**📈 黑匣子分析（对标 BF Blackbox Explorer）**
- 打开 .bbl / .bfl 二进制日志（内置官方解码器），**多段飞行记录自动识别、下拉切换**
- **日志信息面板**：固件版本、机名、板子、PID 循环周期、PID 值、滤波配置等头部元数据
- **多轨道堆叠视图**：每个通道一条独立轨道，共享时间轴（BF 黑匣子浏览器同款布局）
- **鼠标游标读数**：移动鼠标显示该时刻各通道精确数值
- **时间范围裁剪**：只看指定区间
- **频谱分析（FFT）**：自动标注噪声峰频率，指导滤波器设置
- 通道开关选择（BF 同款 toggle 样式）、中文名、归一化对比、统计信息
- **📥 从飞控下载**：MSPv2 大帧读取板载闪存（约 47KB/s），支持只下载"最近 N MB"
  并自动向前定位最近一次飞行的日志起点，下载后可自动清空闪存
- **🔀 双日志对比模式（v0.7 新增）**：加载第二段日志叠加显示（橙色曲线），
  调参前后效果一目了然，统计区显示"当前均值 vs 对比均值"
- **✈️ 日志类型智能判别（v0.7 新增）**：打开日志自动判断是"正常飞行数据"还是
  "疑似地面空转（通电未装桨）"——依据平均电流、陀螺仪 RMS 噪声、姿态设定活动度
  等特征打分，给出置信度和判别理由，空转日志会在状态栏提醒
- **🏷 日志备注标签（v0.99）**：每段日志可写备注（如"5寸花飞/旧PID"），
  保存在 `logs/log_tags.json`，下拉列表条目自动带 🏷 前缀
- **📷 图表截图（v0.99）**：曲线视图一键存 PNG（`logs/screenshots/`），
  方便发交流群讨论
- 崩溃自动记录 `logs/crash.log`（界面异常弹窗提示，不再无声消失）

**🌀 扫频调参（招牌功能，BF2026 Chirp 同源系统辨识，无 AI 猜测）**
- 从黑匣子日志的 setpoint→gyro 数据做 **Welch 互谱频率响应估计**，
  与 BF2026 Chirp Autotune 同一教科书方法，但**不需要刷 2026 固件**——
  普通飞行日志（含翻滚/甩杆动作）即可辨识
- **伯德图可视化 V1.0（v0.99，超越 BF 官方极简曲线）**：
  三轴独立/叠加切换（幅值 dB + 相位 + 相干性三联图，对数频率轴）；
  **谐振峰红圈自动标注** + 频率读数 + 危险区底纹；**带宽方块标注**；
  **相位裕度菱形点标注**；鼠标悬浮读取任意点坐标（频率/增益/相位）；
  **📷 一键截图保存** PNG（`logs/screenshots/`，发交流群讨论神器）
- **实测指标表**：带宽 Hz、相位裕度 °、灵敏度峰值 dB@Hz（>6dB 危险线）、
  相干性（BF 经验 80%+ 可信）、谐振峰定位
- **公式化精准建议**（每条带数学依据，确定性可复现）：
  带宽失衡→慢轴 P/D 按比例上调；相位裕度 <45°→降 D 或加强滤波；
  灵敏度峰值超线→陷波频率；低频跟踪不足→I 项/滤波检查
- **数据质量门**：相干性不足时如实拒绝给建议，指导重飞采集
  （3 次油门斜坡 + 各轴 2~3 次干脆翻滚，约 20 秒）
- 一键应用 PID 建议到飞控（P/D 百分比缩放，自动备份 + 写后读回校验）
- 引擎经过已知被控对象仿真验证：带宽辨识误差 1%，谐振峰定位 ±2Hz

## 扫频调参指南

### Chirp 原理（为什么不用 AI 猜）

BF2026 的 Chirp Autotune 让飞控激励信号从低频到高频**对数扫频**（类似雷达
 chirp 信号），记录机体在每个频率下的响应，算出**频率响应函数**——这是控制
理论里的教科书方法（系统辨识）。ApexFlight 更进一步：**不需要刷 2026 固件**，
普通飞行日志里你做的翻滚、甩杆、油门变化本身就包含了宽频激励，软件用
**Welch 互谱法**从 setpoint→gyro 数据估计出同样的频率响应。

简单说：PID 参数决定了机体对不同频率指令的"跟手程度"，把这个"程度"按频率
画出来就是伯德图（Bode plot）。看到图，就知道哪里该加哪里该减——是**算出来**
的，不是猜的。

### 伯德图指标怎么看

| 指标 | 含义 | 健康参考 |
| --- | --- | --- |
| **带宽（Bandwidth, Hz）** | 幅值降到 -3dB 的频率：机体能多快响应指令 | 三轴接近（差 <20%）；横滚≈俯仰>偏航是正常的 |
| **相位裕度（PM, °）** | 距离自激振荡还有多少余量 | ≥45° 稳健；<30° 容易洗桨/振荡 |
| **灵敏度峰值（dB@Hz）** | 对噪声/扰动的最大放大倍数 | <6dB；超线说明该频率一碰就炸 |
| **谐振峰（Hz）** | 机架/桨的机械共振频率 | 红圈标注，需陷波滤波或机械排查 |
| **相干性（0~1）** | 数据可信度：输出有多少真是输入引起的 | ≥0.8 可信；低了说明激励不够，重飞采集 |

图上的红色底纹区 = 谐振危险区；方块 = 带宽点；菱形 = 相位裕度点。
鼠标悬浮可读出任意点的频率/增益/相位精确值。

### 建议参数代表什么

- **P（比例）**：对偏差的即时反应强度。带宽不足→慢轴 P 按比例上调
- **I（积分）**：消除持续偏差（抗风/抗漂移）。低频跟踪不足→查 I 项
- **D（微分）**：抑制过冲、增加阻尼。相位裕度低→降 D 或加强 D 项滤波
- **陷波频率**：灵敏度峰值/谐振峰所在 Hz→在该频率开 Notch 滤波器
- **低通截止**：高频噪声多时下调；调太低会引入相位延迟反而降低 PM
